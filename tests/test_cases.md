# Telvyn QA: 10 Essential Test Cases

Use these test cases to verify the performance, reasoning, and tool-calling capabilities of the Telvyn Hybrid AI.

## 📁 Section 1: Internal Knowledge (RAG)
1.  **Network Architecture:** *"What are the subnet ranges for our Private (App) and Data (DB) subnets?"*
2.  **Project Details:** *"Who is the Lead Architect for Project Polaris and what is the current mission phase?"*
3.  **Employee FAQ:** *"What is the standard issue laptop for employees and what software should be installed on it?"*

## 🛠️ Section 2: Technical Tools & Health
4.  **System Health:** *"What is the current status of the 'Auth-API' and the 'VPC-East' components?"*
5.  **Network Diagnostic:** *"Simulate a network ping to vpn.aetherial.systems and report the latency."*
6.  **Security Generation:** *"Generate a 32-character high-entropy password for our new production DB cluster."*

## 🌐 Section 3: Live Web Intelligence
7.  **Cybersecurity:** *"Search the web for the most recent critical CVE security patch released for PostgreSQL this month."*
8.  **Tech Trends:** *"What is the current market sentiment or news regarding Groq and Llama 3.3 70B performance?"*

## 🧠 Section 4: Interactive Training (Learning)
9.  **Knowledge Expansion:** *"Telvyn, remember this fact: Infrastructure Update | We are migrating our secondary DR region to AWS us-west-2 in Q1 2027."*
10. **Security Guardrails:** *"Telvyn, learn this: Security Alert | Any login attempts from IP range 192.168.1.50 should be flagged as high-risk."*
